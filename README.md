
# BOSS DEFEATING GAME (2D)

2D boss defeating game developed in Java. This game was created as university semester project.




## Installation

Before installing the game you need to install JDK (Java SE Development Kit):
- https://www.oracle.com/java/technologies/downloads/

You can download release of the game from this repository releases. Unzip the downloaded file. Then just run ".jar" file to start the game.

Or you can clone repository and download source code. Then you can edit it through any code editor supporting Java compilation. To run game start "Main" class.


    
## Controls

Use `WASD` to move your character on map. On map you can find level enters. Every level contain boss which has to be defeated by hitting him with bullet. You fire a bullet by pressing `L`. Jumping is able with `SPACE`.
